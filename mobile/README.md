# Невеста Агнца

Мобильное приложение церкви «Невеста Агнца» для iOS и Android. Исходный сайт на Astro служит источником расписания, проповедей и контактов.

## Запуск

В каталоге `mobile` используйте Node.js 24.

```sh
npm ci
npm run typecheck
npm start
npm run build:web
```

Веб-сборка находится в `dist/`. На телефоне она умеет сохранить событие в файл `.ics` с напоминанием за час. Нативная версия открывает системный календарь и может отдельно планировать локальное уведомление в приложении. Продолжительность при экспорте можно изменить в системном календаре. Если в расписании указано только начало, приложение подставляет один час.

Тестовую нативную сборку можно выпустить командой `npx eas-cli build --profile preview` с настроенными учётными данными EAS и Apple для iOS.

## Контент

После изменения `src/data/contacts.ts` или коллекций `src/content` исходного сайта запустите `npm run sync:content` из каталога `mobile` и зафиксируйте обновлённый `src/church-content.json`. Для разового события укажите `startsAt` в ISO 8601 с годом и часовым поясом. Поля `endsAt` и описания можно задать при необходимости.

Видео открываются на Rutube. Когда у церкви появится прямая HTTPS-ссылка на аудиофайл, добавьте её в `scripts/audio-sources.json` по идентификатору Rutube из соответствующей проповеди и повторите синхронизацию. Слушатель увидит кнопку «Слушать аудио». Нативный плеер может продолжать воспроизведение при свёрнутом приложении или заблокированном телефоне.

Личные заметки и избранное сохраняются на устройстве. Раздел пожертвований открывает страницу церкви.
